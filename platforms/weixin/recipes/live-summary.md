# 视频号直播总结

人在电脑版微信里看一场视频号直播（自己的或别人的），不用一直守着听：囤囤鼠在后台把主播说的话每分钟转成一段文字，
连同评论区一起记下来；直播中或结束后交给 Agent，整理出讲了什么、卖了什么、观众在问什么。
桥只做桥：本场景是给 Agent 的提示词模板，分析在 Agent 里完成；**不发评论、不点赞、不下单**。

## 需要

- 平台包 `weixin` 0.4 以上（映射卡 `weixin/live-speech`、`weixin/live-comment`）
- 「视频号完整数据」插件 0.10 以上，「微信视频号」插件已启用
- 设置 → 语音转写：选本机模型或填在线服务（没设就只有评论，没有口播）
- 人在电脑版微信里进了直播间，并且一直开着（关掉直播间 90 秒内停止转写）

## 字段

口播 `live_speech`：`id, live_id, content（这一分钟主播说的话）, secs, create_time（这段开始的时间，秒）`

评论 `live_comment`：`id, live_id, seq（发言顺序）, nickname, user_id, content, identity（3 = 主播或场控，1、2 = 观众）, create_time（收到的时间，秒）`

## Agent 提示词模板

把下面整段交给 Agent：

```
用 Nuttle 的 MCP 工具，帮我总结一场我在看的视频号直播。只用已经记录的数据，不要尝试去抓取。

步骤：
1. 调 query_entities(platform="weixin", kind="live_speech", order_by="create_time", desc=false, limit=200) 取口播；
   有几个 live_id 就列出来（每场的开始、结束时间和段数），默认总结最新那场，用 keyword=<live_id> 只取这一场。
   超过 200 段就用 since 往下翻，直到读完。
2. 同样取 kind="live_comment"（keyword=<live_id>，order_by="create_time"）。identity=3 的是主播或场控打的字，
   常是商品卖点、价格、规格，和口播一起当主播的话；其余是观众。
3. 按时间顺序通读口播（转写有同音错字、数字错，按上下文理解，引用时标「转写」），整理：
   - 时间线：每 10~15 分钟一段，写这段在讲什么（讲了哪个商品 / 哪个话题）
   - 商品清单：商品名、规格、直播价、原价 / 对比价、赠品、链接号（主播说的「X 号链接」）、限时限量的说法
   - 知识点：主播讲的方法、经验、行业信息，去掉催单话术后能单独拿出来用的内容
   - 观众关注：评论里反复问的问题、顾虑、要求（去掉「来了」和刷屏口号），主播有没有回答、怎么答的
4. 输出：
   - 一句话概括这场直播
   - 时间线
   - 商品清单（表格）
   - 知识点
   - 观众关注 Top 5（附原评论）
   - 主播用到的促单话术（逐字引用 2~3 句）

规矩：价格、规格以主播打的字（identity=3）为准，口播里的数字可能转错，对不上时两个都列出来；引用评论要逐字；
不编造直播里没有的内容；不改动、不删除任何映射。
```

## 已知限制

- 只记录人在直播间里的这段时间；进来之前、离开之后的不会有。
- 口播是机器转写：同音字、数字、品牌名可能有错；主播背景音乐大时更容易出错。
- 进场（「来了」）、下单提示、礼物不算评论；在线人数、点赞数在原始接口 `/nuttle/wxlive/GetLiveMsg` 里（`curParticipantCount`、`curLikeCnt`）。
