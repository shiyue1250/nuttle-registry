# 整理微信收藏

你平时把喜欢的文章、视频、链接点了收藏，但从来没整理过。
Agent 从囤囤鼠已读入的「微信收藏」里，按主题归类、去重、排出一份可行动的清单。
桥只做桥：本场景是给 Agent 的提示词模板，只读已记录的数据，不发消息、不动微信。

## 需要

- 平台包 `wechat-local`（映射卡 `wechat-local/favorite`）
- 在「平台 → 微信」里开启「微信收藏」并同步过（仅 Windows）

## 字段

`id, kind_label（类型）, create_time（秒）, title, content（正文纯文本）, url（链接类）, source（来源）`

## Agent 提示词模板

```
用 Nuttle 的 MCP 工具，读取我的微信收藏，帮我把囤的内容整理成一份清单。只用已记录的数据，不要尝试抓取、更不要发任何消息。

步骤：
1. 调 query_entities(platform="wechat-local", kind="favorite", limit=200)。
2. 按主题聚类（根据 title + content），每类给一个名字；同一篇文章 / 同一个链接重复收藏的合并成一条。
3. 每条标注：标题、类型（文章 / 视频 / 链接 / 文件 / 文字）、来源、收藏时间、链接。
4. 输出：
   - 概览：一共多少条、几类、时间跨度
   - 分主题清单：每类下按时间列条目（标题 + 链接 + 来源）
   - 「可以清掉的」：明显重复、或过期失效的
   - 「值得再看的 5 条」：挑出信息密度高的，附一句为什么
规矩：标题和正文引用要逐字；不编造；不改动、不删除任何实体。
```

## 已知限制

- 仅 Windows，且要微信 4.x 登录运行；收藏里的图片 / 文件本身不下载，只记标题与元信息。
