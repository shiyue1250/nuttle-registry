# 公众号爆文拆解

人在微信里读了一批同领域的公众号文章（自己关注的、竞品的、刷到的爆款），Agent 从这些看过的文章里，
拆出标题写法、选题角度、结构套路和开头钩子，整理成可复用的写作清单。
桥只做桥：本场景是给 Agent 的提示词模板，分析在 Agent 里完成；**不发文、不评论、不点赞**。

## 需要

- 平台包 `weixin-mp`（映射卡 `weixin-mp/article`；实体类型 `article`）
- 「公众号」插件卡显示「已启用」（含「公众号文章」插件）
- 人在电脑版微信或浏览器里打开过这些文章（只有打开过的才会被记录）

## 字段

文章 `article`：`id, title, account（公众号）, author, create_time（秒）, desc（摘要）, content（正文纯文本）, image_count, original（原创）, url`

## Agent 提示词模板

把下面整段交给 Agent：

```
用 Nuttle 的 MCP 工具，读取我打开过的公众号文章，帮我拆解爆文写法。只用已经记录的数据，不要尝试去抓取。

输入：一个领域或关键词（例如「职场沟通」「AI 工具」），可选：限定几个公众号名。

步骤：
1. 调 query_entities(platform="weixin-mp", kind="article", keyword=<关键词>, order_by="create_time", limit=50) 找相关文章；
   有限定公众号就只留 account 匹配的。列出候选（标题、公众号、发布时间、字数、链接）。
2. 逐篇读 content，拆出：
   - 标题公式：数字型 / 反常识 / 痛点提问 / 身份代入 / 利益承诺……，每篇标一种，附原标题
   - 开头钩子：前 3 句用了什么手法（场景、冲突、数据、提问）
   - 结构：总分总 / 清单体 / 故事 + 方法 / 对比……，标出小标题骨架
   - 选题角度：同一话题从哪个切口切入
3. 汇总：每类标题公式出现几次、哪个公众号最常用；最常见的 3 种结构；可直接套用的 5 个标题模板（附来源文章）。
4. 输出：
   - 概览：读了几篇、来自几个公众号、时间跨度
   - 标题公式表：公式 | 篇数 | 例子（原标题 + 链接）
   - 开头钩子与结构清单
   - 给我的 5 个选题建议，每个附「参考了哪几篇」

规矩：引用标题和原文要逐字；不编造文章里没有的内容；不改动、不删除任何映射。
```

## 已知限制

- 只记录打开过的文章；阅读数、点赞、留言暂未接入。
- 图片消息、视频号转发这类没有正文的文章，content 为空。
